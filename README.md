# DOTA: Карточные войны

Пошаговая карточная версия Dota 2. 16 героев, у каждого — своя колода: общие базовые карты плюс уникальные карты способностей. Бой 5 на 5 на карте с тремя линиями, лесами, Рошаном и Древними. Всё — фарм, перемещения, ганги, сражения, пуш башен, убийство Рошана — происходит через карты из колоды героя.

## Запуск

Сборка не нужна — это статическая страница на чистом JavaScript.

- Просто откройте `index.html` в браузере (двойной клик), **или**
- запустите локальный сервер: `python3 -m http.server` и откройте <http://localhost:8000>.

Шрифты подгружаются из Google Fonts; без интернета игра работает со стандартными шрифтами.

## Режимы

На экране выбора героев вы собираете **5 героев для каждой стороны** (поочерёдно, как в режиме капитанов, или кнопкой «Случайный состав»), затем выбираете режим:

| Режим | Описание |
|---|---|
| Играть за Свет / Тьму | Вы управляете всеми пятью героями своей стороны, противником управляет ИИ |
| ИИ против ИИ | Наблюдайте за матчем; скорость 1×/2×/4× и пауза в верхней панели |
| Два игрока | Обе стороны управляются людьми за одним экраном |

## Механики

- **Раунд = «минута» игры.** Все живые герои ходят по очереди, стороны чередуются, внутри стороны порядок по ловкости.
- **Ход героя:** восстановление здоровья/маны → добор руки до 5 карт → 1 перемещение в соседнюю зону (с сапогами — 2) и 1 карта в любом порядке. Раз в ход можно сбросить карту и взять новую.
- **Колода:** базовые карты (Удар ×3, Фарм ×3, Натиск ×2, Свиток телепорта, Лечебная мазь, Засада) + карты способностей (2 копии за изученную способность, 1 за ультимейт) + карты активных предметов.
- **Атрибуты:** сила → здоровье и регенерация; ловкость → броня и скорость атаки; интеллект → мана и усиление заклинаний; основной атрибут добавляется к урону (универсальные — 45% суммы).
- **Уровни 1–20:** очки способностей (ульта на 6/12/18, обычные — не выше половины уровня), таланты на 10/15/20.
- **Экономика:** фарм на линиях и в лесах, пассивное золото, награды за убийства, башни и Рошана; 19 предметов в магазине.
- **Эффекты:** оглушение, сглаз, обездвиживание, безмолвие, урон со временем, невидимость, щиты, невосприимчивость к магии (BKB), неглубокая могила, крит, уклонение, вампиризм, рассечение.
- **Объекты:** по 3 башни на линию (бьют в ответ), казармы → мега-крипы, Древний; Рошан даёт Эгиду.

## Портреты героев

Сейчас у всех героев одна картинка-заглушка (`assets/hero-placeholder.jpg`), окрашенная в свой оттенок. Чтобы поставить настоящий портрет, положите файл, например `assets/heroes/axe.jpg`, и добавьте герою в `js/data.js` поле `img`:

```js
hero('axe', {
  name: 'Axe', ..., img: 'assets/heroes/axe.jpg',
```

С заданным `img` цветовой фильтр не применяется. Лучше всего подходят вертикальные изображения с лицом в верхней трети.

## Баланс

Баланс проверен симуляцией матчей ИИ против ИИ со случайными составами:

```bash
node tools/sim.js 600 1 4   # игр, сид, потоков
```

Скрипт выводит процент побед, У/С/П, уровень и ценность каждого героя. Цифры героев подбирались так, чтобы процент побед каждого был близок к 50%.

## Структура

```
index.html        — разметка экранов
css/style.css     — оформление
js/data.js        — зоны карты, герои, карты, предметы, таланты
js/engine.js      — правила игры (работает и в браузере, и в Node)
js/ai.js          — ИИ: стратегия команды + перебор ходов с оценкой позиции
js/ui.js          — интерфейс, анимации, управление
tools/sim.js      — симулятор для проверки баланса
```
